| Sprint 3 | Objetivo, alcance, historias y capacidad. |
| Mejoras documentales | Correcciones y comparación de artefactos. |
| Arquitectura | Contextos, C4, comunicaciones y modelo DDD. |
| Persistencia | PostgreSQL, EF Core y migraciones. |
| API | Recursos REST, autorización y OpenAPI. |
| Demostración | Recorridos de Coordinador Logístico y Cliente de Carga. |
| Calidad y publicación | Pruebas, versiones, entornos y recibos. |
| Validación | Método, participantes, tareas y resultados observados. |
| Evaluación heurística | Problemas, severidad y recomendaciones. |
| Colaboración | Tablero, contribuciones, revisiones y Student Outcome. |
| Cierre | Resultados y conclusiones. |
