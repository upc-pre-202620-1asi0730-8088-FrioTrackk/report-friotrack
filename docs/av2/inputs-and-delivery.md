# Entrega AV2

Los formatos corresponden al enunciado UPC 1ASI0730, periodo 202620, AV2 semana 12.

## Documentos y artefactos

| Entregable | Contenido y formato |
| --- | --- |
| Reporte acumulativo | Markdown y PDF; capítulos, versiones, colaboración, Student Outcome, validación y anexos. |
| Presentación | PowerPoint y PDF; integrantes, problema, incremento, demostración y resultados. |
| Evaluación individual | Word y PDF; responsabilidades y calificaciones emitidas por el Team Leader. |
| Complementos | ZIP con los artefactos y proyectos aplicables, sin credenciales ni bases privadas. |
| Validación | Entre 3 y 5 entrevistas por segmento, con ficha, captura, resumen y referencia al video. |
| Evaluación heurística | Formato del Anexo D, severidad, evidencia y recomendaciones. |
| Videos | Product, Team, navegación, validación consolidada y exposición AV2. |

## Productos digitales

Landing y Web Application publicadas; Web Services con persistencia relacional y documentación OpenAPI. Los recibos de cada publicación identifican fecha, versión y comprobaciones. El incremento AV2 utiliza ASP.NET Core, EF Core, PostgreSQL 17 y una SPA Vue con soporte ES/EN.
