# Archivo de Figma – FríoTrack (Bloque 4: Product Design)

Este directorio contiene el material con el que se armó el archivo de Figma del Bloque 4 del proyecto FríoTrack (BlackStartup, 1ASI0730 Aplicaciones Web, NRC 8088).

**Archivo de Figma:** https://www.figma.com/design/eJ6Ceq0H0FP0xWseNnKFFv

**Landing Page publicada:** https://friotracktb1bce6db1b.z22.web.core.windows.net/landing/

## Páginas del archivo

| Página | Contenido |
| :--- | :--- |
| Portada | Título del proyecto y contenido del archivo. |
| 4.1 Style Guidelines | Logotipo y variantes, paleta de color, tipografía (Inter), espaciado, radios y elevación, iconografía (PrimeIcons), tono y voz, componentes. |
| 4.2 IA y User Flows | Mapas del sitio de la landing y de la aplicación web, y los tres user flows (programar un envío, atender una alerta, consulta del cliente). |

## Carpeta `svg/`

Los 12 archivos SVG son la fuente de las páginas del archivo. Se generaron desde los mismos prototipos HTML que ilustran el Capítulo IV, de modo que el diseño de Figma y las figuras del informe coinciden. Cada pantalla es un *frame* independiente con textos (fuente Inter) y formas editables.

## Cómo reimportar un SVG en Figma

1. Abra el archivo SVG en un editor de texto y copie todo su contenido.
2. En Figma, sobre la página de destino, pegue con `Ctrl + V`. Figma crea los frames y las capas editables.
3. Con la fuente Inter disponible en Figma no hace falta ajustar nada más.

## Alcance

El archivo es un entregable de diseño visual (wireframes, mock-ups y guía de estilo). No incluye componentes, variables ni enlaces de prototipo de Figma; el prototipo navegable del proyecto es el archivo `assets/prototype/friotrack-prototype.html`.
