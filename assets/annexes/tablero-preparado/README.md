# Catálogo de tareas de FríoTrack

Corte documental: 11/11/2026. El catálogo contiene 58 tareas del reporte: 8 de Sprint 1 y 50 de Sprint 2. Sus listas corresponden al análisis del informe y no constituyen un export del tablero.

Tablero de referencia: <https://trello.com/b/6qrvOukt/blackstartup-fr%C3%ADotrack>.

## Archivos del catálogo

| Archivo | Contenido |
| --- | --- |
| `tarjetas-preparadas-58.csv` y `.json` | IDs, historias, descripciones, estimaciones y atribuciones históricas. |
| `to-do-titulos.txt` | 24 títulos clasificados como To Do. |
| `to-review-titulos.txt` | 34 títulos clasificados como To Review. |
| `in-process-titulos.txt` y `done-titulos.txt` | Sin tareas clasificadas en este corte documental. |
| `descripciones-tarjetas.md` | Descripción de las tarjetas. |
| `registro-aceptacion-58.csv` | Formato de registro de la revisión por tarea. |
| `CHECKLIST-ACEPTACION.md` | Criterios de aceptación y estructura de evidencia. |

Las horas son estimaciones de revisión posteriores al trabajo original. La atribución histórica y la asignación actual son campos distintos. Los estados del catálogo conservan el corte indicado.

## Estados

| Estado | Significado |
| --- | --- |
| To Do | Trabajo sin inicio registrado. |
| In Process | Trabajo iniciado. |
| To Review | Resultado disponible para revisión. |
| Done | Aceptación registrada. |

## Intercambio de datos

El intercambio con Trello utiliza IDs de tarea para relacionar tarjetas y evitar duplicados. Los exports del tablero y las capturas fechadas constituyen evidencias distintas del catálogo documental.
